---
title: "Toolsets"
description: "Expose only the tools you use and cut your AI's context cost."
---

Most MCP clients load **every tool schema into the model's context at the start of every conversation**. With AdLoop's full catalog that is a noticeable share of the context window, paid before you type a word. Toolsets let you expose a subset.

## The toolsets

| Toolset | Covers |
|---------|--------|
| `ads` | Google Ads reads, writes, and planning (Keyword Planner) |
| `ga4` | Google Analytics reports, realtime, funnels, attribution, property setup and audit, key events, annotations, custom dimensions and metrics, data retention |
| `tracking` | Cross-channel attribution, conversion tracking setup and tracking code generation |
| `gtm` | Google Tag Manager audits and reads |
| `gsc` | Search Console reads |
| `web` | PageSpeed / Core Web Vitals |
| `merchant` | Merchant Center feed health |
| `reddit` | Reddit Ads reads, writes, and planning |
| `microsoft_ads` | Microsoft Advertising (Bing) reads and campaign management. Open-source AdLoop only for now |

### Narrowing Google Ads

You can also pick part of Google Ads instead of the whole `ads` toolset (on AdLoop Cloud: tick Google Ads when creating a key and choose its scope):

| Subset | Covers |
|--------|--------|
| `ads:read` | Ads reports, GAQL, and the Ads/Analytics cross-checks (`attribution_check`, `check_key_event_imports`, `analyze_campaign_conversions`, `landing_page_analysis`) |
| `ads:write` | Ads drafts and changes, and the conversion tracking setup. Turns on `ads:read` too, because a draft needs the reads first (IDs, bidding strategy) |
| `ads:plan` | Keyword ideas and budget forecasts (`discover_keywords`, `estimate_budget`) |

`ads:read,ga4` suits audits and diagnosis; `ads:plan` alone suits keyword research.

`health_check` and `confirm_and_apply` are always included, whatever you select, so diagnostics and the [safety gate](/concepts/safety-model) can never be filtered away.

## What it saves

Measured against the live tools/list: `ads:read,ga4` costs about 40% of `ads,ga4`, and `ads:plan` alone about 5% of the full catalog. Toolsets are per **consumer**, not per install: one AdLoop setup can serve a trimmed Cursor and a full-catalog Claude Code side by side.

## AdLoop Cloud: per API key

Pick toolsets when creating a key under **Settings → API keys**. The server then trims that key's advertised tool list and refuses calls outside the selection, with a clear message pointing back to the dashboard. Existing keys are unrestricted until you say otherwise.

## Self-hosted: environment variable

```json
"env": { "ADLOOP_TOOLSETS": "ads:read,ga4" }
```

Set it in your MCP client's configuration (the `adloop init` wizard offers this and writes it into the snippets). Unset means the full catalog; unknown names fail at startup listing the valid ones.

Without the variable, a platform you haven't set up stays out of the list: with no Reddit app in the config, the Reddit Ads tools are hidden (the same goes for Microsoft Advertising) and `health_check` names the setup step under `hidden_toolsets`. Set the platform up and restart the server to get its tools, or name it in `ADLOOP_TOOLSETS` to show them anyway. Google's toolsets are always listed, since Google can sign in through Application Default Credentials with nothing in the config.
