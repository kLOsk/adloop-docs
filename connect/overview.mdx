AdLoop Cloud is a remote MCP server at:

```
https://mcp.getadloop.com/mcp
```

Any AI app that can add a remote MCP server can use it. There are two ways to sign in:

- **Sign in with AdLoop (OAuth).** The app opens AdLoop's consent page, you approve, done. Nothing to copy. The connection uses your whole workspace.
- **API key.** You paste a key from **Settings → API keys** in the [dashboard](https://getadloop.com) into the app's config, sent as `Authorization: Bearer alc_…`. Keys can be [restricted](/cloud/api-keys): read-only, single clients, chosen toolsets.

Every write goes through the same [preview and confirm flow](/concepts/safety-model), whichever app you use.

## Which sign-in to use

| | OAuth (sign in with AdLoop) | API key |
|---|---|---|
| Setup | Click through a consent page | Copy a key into a config file |
| Scope | Whole workspace | Restrictable per key (read-only, clients, toolsets) |
| Agencies | Name the client in your request | Bind the key to one client |
| Revoke | Settings → API keys → Connected AI apps | Settings → API keys |

Chat apps in the browser only offer OAuth. Coding agents offer both; an API key is handy when you want a read-only or client-scoped connection, or on a machine without a browser.
